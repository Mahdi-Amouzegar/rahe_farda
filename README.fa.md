## ۱. راه فردا چیست؟

راه فردا یک **برنامه‌ریز شخصی فارسی‌محور و RTL-native** است که بر پایه‌ی **تقویم جلالی (هجری شمسی)** طراحی شده است.

هدف آن کمک به تبدیل نیت‌ها و کارهای پراکنده به برنامه‌های قابل مدیریت است: مدیریت کارهای روزانه، تقسیم فعالیت‌های بزرگ‌تر به چند مرحله، برنامه‌ریزی فعالیت‌های تکرارشونده، ثبت مکان و توضیحات، و ادامه‌ی کار حتی زمانی که اینترنت در دسترس نیست.

راه فردا **یک برنامه‌ریز میلادی با پوسته‌ی فارسی نیست.** تاریخ‌ها، اعداد، ورود متن، جریان تقویم و رابط کاربری از ابتدا با درنظرگرفتن کاربران فارسی‌زبان طراحی شده‌اند و انگلیسی نیز به‌عنوان زبان دوم پشتیبانی می‌شود.

### سه نوع فعالیت

| نوع | توضیح |
|---|---|
| **کار** | یک فعالیت مستقل، با تاریخ، زمان یا مکان اختیاری. |
| **برنامه** | یک فعالیت چندمرحله‌ای متشکل از چند کار کوچک‌تر. |
| **دوره** | یک فعالیت تکرارشونده که طبق یک برنامه زمانی تکرار می‌شود. |

## ۲. ویژگی‌های شاخص

- 📅 **برنامه‌ریزی جلالی‌محور** — تقویم فارسی بخش اصلی تجربه است.
- 📴 **قابل استفاده به‌صورت آفلاین** — قابلیت‌های اصلی برنامه به اتصال دائمی وابسته نیستند.
- 💾 **Local-first** — داده‌های روزمره‌ی برنامه‌ریزی به‌صورت پیش‌فرض روی دستگاه نگهداری می‌شوند.
- 🌐 **دو‌زبانه** — فارسی (RTL) و انگلیسی (LTR).
- 📱 **قابل نصب** — امکان استفاده به‌عنوان وب‌اپلیکیشن نصب‌شونده.
- 🗺️ **مکان‌محور** — ذخیره‌ی مکان، جستجوی موقعیت، محاسبه‌ی مسیر و قابلیت‌های وابسته به موقعیت.
- 🎤 **ورودی صوتی** — پشتیبانی از ورود گفتاری فارسی و انگلیسی در محیط‌های سازگار.
- 🔄 **همگام‌سازی اختیاری بین دستگاه‌ها** — در صورت فعال‌سازی همگام‌سازی، ادامه‌ی کار روی دستگاه‌های دیگر.
- 👥 **فضاهای اشتراکی** — گروه‌ها، کارهای گروهی، گفتگو، دعوت و اشتراک‌گذاری کارها.
- 🔎 **جستجو** — جستجوی کاربران و گروه‌های عمومی از داخل برنامه.
- 🌓 **تم روشن، تاریک و خودکار**.
- ♿ **رابط واکنش‌گرا و مناسب استفاده با صفحه‌کلید** برای موبایل و دسکتاپ.

## ۵. اصول طراحی محصول

### Local-first

راه فردا طوری طراحی شده است که برنامه‌ریزی روزمره به اتصال دائمی اینترنت وابسته نباشد.

### فارسی از ابتدا

فارسی صرفاً ترجمه‌ی متن انگلیسی نیست. راست‌به‌چپ بودن رابط، تاریخ جلالی، اعداد فارسی و شیوه‌ی ورود تاریخ در سراسر تجربه‌ی کاربری در نظر گرفته شده‌اند.

### همگام‌سازی اختیاری است

همگام‌سازی ابری بخشی اختیاری از تجربه است. برنامه‌ریز اصلی را می‌توان به‌صورت محلی و بدون ایجاد حساب کاربری استفاده کرد.

### سادگی در سطح رابط

هدف این است که استفاده‌ی روزمره ساده و قابل فهم باقی بماند، در حالی که برای جریان‌های کاری پیچیده‌تر نیز امکانات کافی وجود داشته باشد.

## ۶. شروع کار

### به‌عنوان کاربر

**[→ باز کردن دموی زنده](https://mahdi-amouzegar.github.io/rahe_farda/)**

می‌توانید برنامه را مستقیماً در یک مرورگر مدرن اجرا کنید یا در صورت پشتیبانی مرورگر، آن را به‌عنوان وب‌اپلیکیشن نصب کنید.

### به‌عنوان توسعه‌دهنده

ریپازیتوری را دریافت و وابستگی‌ها را نصب کنید:

    git clone https://github.com/Mahdi-Amouzegar/rahe_farda.git
    cd rahe_farda
    npm install

اجرای محیط توسعه:

    npm run dev

ساخت نسخه‌ی نهایی:

    npm run build

اجرای تست‌ها:

    npm test
